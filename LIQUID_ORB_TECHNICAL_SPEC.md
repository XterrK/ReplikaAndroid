# Изменения V1.6

V1.6 заменяет внутреннюю поверхность: domain-warped silk folds, сфера/рефракция/мягкий Fresnel, ellipse highlights; базовый радиус .39 размера canvas. Контур использует меньшую voice-модуляцию, touch/area preservation сохранены. Новый shader и Canvas fallback находятся в LiquidVoiceOrb.kt. Прежняя спецификация V1.5 ниже историческая.

# Liquid Voice Orb — V1.5

Текущая спецификация; V1.4 исходник сохранён в прежнем Human Review ZIP. Детальное дополнение и проверки: [LIQUID_ORB_V1_5.md](LIQUID_ORB_V1_5.md).

## Сигнал и границы ответственности

`AppViewModel` сохраняет AAC/M4A тем же MediaRecorder (MIC, 48 kHz, 128 kbit/s), что V1.3. `maxAmplitude` читается каждые 50 ms только во время активной записи. Это peak envelope, не RMS, не высота тона и не калиброванный dB SPL. Дополнительная сессия микрофона, FFT или inference не создаются. Orb не меняет аудиосэмплы, Room schema или thermal policy. Изменение ASR до GigaAM v3 и ограниченное усиление очень тихого VAD/ASR-буфера описаны отдельно в ASR_QUALITY_V1_5.md.

`VoiceEnvelope`: нормализация 0…1; окно 80 samples, тихий 15-й percentile оценивает фон, обновление каждые 10 samples после 20. Noise floor ограничен 0.0003…0.018: продолжительная речь не должна исчезать как шум. Gate = 1.35×floor; логарифмическая компрессия log(1+64x)/log(65), exponent 0.82; attack 38 ms / release 320 ms. Без разрешения чтение MediaRecorder не начинается и voiceLevel остаётся нулём. Тихое декоративное движение не является сигналом речи. Рост noise floor при уже видимом устойчивом входе >2×floor заморожен, чтобы длительный тихий сигнал не изучался как фон; понижение floor и затухание на паузах сохранены. Это амплитудный индикатор, не классификатор речи/шума.

## Физика и контур

`OrbDynamics` — чистый Kotlin. Общий spring stiffness 88, damping 11.8; target = active×0.09 + envelope×0.125. Пять мод (гармоники 2…6) stiffness 36…76, damping 5.7, локальный коэффициент 2.5. Начало звука даёт ограниченный onset impulse. Подшаги ≤1/120 s, входной dt ≤50 ms; expansion −2.5…23.5%, локальная радиальная поправка ±20%.

96 полярных точек превращаются в замкнутый cubic Bézier Path. Контур нормализуется по площади, массивы/path переиспользуются. Tap/drag: локальная волна, инерция, эллиптические взаимно обратные оси, ограниченное смещение центра. После отпускания оболочка возвращается пружинами. Жесты меняют только OrbDynamics; настоящий `voiceLevel` и рекордер не затрагиваются. Правая VU-шкала подписана непосредственно на реальный voiceLevel и выключена вне Recording.

## Поверхность

API 33+: `RuntimeShader` / `ShaderBrush`, одна ограниченная orb draw area. AGSL оценивает глубину z по расстоянию до той же деформированной границы; Fresnel-подобный светлый край, сине-лавандовая жидкость, движущийся specular highlight, внутренний свет и мягкая жидкая световая полоса. Материал полупрозрачен, с отдельным отражением/преломлением края; shader output premultiplied. Точные параметры текущей поверхности — в LiquidVoiceOrb.kt. Вне path нет синего фонового слоя. Шейдер создаётся один раз; uniform обновляются на кадре. Ошибка компиляции shader безопасно включает Canvas fallback.

API 26–32: тот же физический path; несколько градиентов, clipPath, мягкий блик, световая полоса и edge stroke. Нет WebView, Unity, 3D-движка, offscreen blur или bitmap на каждый кадр. Fallback имеет меньше глубинных световых деталей, но тот же контур и сигнал.

## Состояния и жизненный цикл

Idle → Permission required (при необходимости) → Starting → Recording ↔ Paused → Stopping → Saved. Ошибки подготовки/остановки/сохранения переходят в Error с реальным сообщением. Запуск/остановка выполняют MediaRecorder IO вне главного потока. Пока запускается сессия, повторный старт блокируется; запрос выхода во время Starting обрабатывается после запуска.

Orb запускает запись из Idle/Saved/Error/Permission required. В Recording/Paused нажатие и drag разминают тело; доступен keyboard focus, semantic click и дополнительное accessibility действие растяжения. Пауза, Продолжить и Остановить — отдельные подписанные кнопки ≥48 dp. Back предлагает сохранить, продолжить или удалить. Уход приложения в фон ставит активную запись на паузу. На успешной остановке файл записывается в существующую Room библиотеку, открывается штатный экран подготовки распознавания. В промежуточной фазе Stopping оболочка успокаивается минимум 450 ms.

## Производительность / доступность

Кадровый счётчик читается только DrawScope, остальные UI узлы не подписаны на него. Геометрические массивы и path переиспользуются. Один раз в секунду учитываются PowerManager.isPowerSaveMode и thermal status: при экономии/умеренном нагреве снижается частота, при SEVERE — сильнее. ML thermal gate не меняется. Анимация только в RESUMED; покой/пауза после settling замирают, активная запись использует frame clock. Системный animator_duration_scale=0 отключает пружинные колебания и обновляет состояние ограниченно. Физика по-прежнему ограничивает уровень; семантика передаёт фазу, без ежекaдровых TalkBack объявлений.

Нативная реакция на физический микрофон телефона и энергопотребление должны проверяться отдельно на реальном устройстве. Эмуляторная запись не доказывает работу микрофона vivo X300.

## Отличия от прототипа

Прототип: Canvas2D, явный slider/test amplitude, тестовые состояния и таймер. Native: реальный MediaRecorder peak, DataStore и Room, AGSL с volume lighting, системные разрешения и жизненный цикл; нет slider. В прототипе и Android idle движение останавливается после settling для экономии энергии. Canvas fallback использует ту же визуальную механику, но не полностью повторяет Fresnel shading AGSL. Изменения являются реализационными, направление C+B не меняется.

Официальные источники: [MediaRecorder](https://developer.android.com/reference/android/media/MediaRecorder), [AGSL brush / API 33+](https://developer.android.com/develop/ui/compose/graphics/draw/brush), [DataStore](https://developer.android.com/topic/libraries/architecture/datastore).

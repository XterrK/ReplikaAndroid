# REPLIKA · Реплика

**Каждое слово можно проверить.** Локальная стенограмма с говорящими, исходным звуком и ручной проверкой. Исследовательская Android-сборка для подготовки к хакатону 6 ноября 2026 года. Критерии хакатона ещё не опубликованы.

Приложение реализует Kotlin / Compose / Room / Media3 / WorkManager и настоящие нативные ML-backend. Состояние проверок и ограничения находятся в [PROJECT_STATE.md](PROJECT_STATE.md) и [TEST_REPORT.md](TEST_REPORT.md). Наличие кода не означает подтверждённую работу на физическом телефоне.

## Сборка

Требуются JDK 17, Android SDK 35, Build Tools 35.0.0, NDK 27.2.12479018 и CMake 3.22.1. Gradle 8.13, AGP 8.9.2, Kotlin 2.1.20. Все тяжёлые инструменты текущего окружения находятся в `F:\ReplikaToolchain`, проект — в `F:\Hackathons\ReplikaAndroid`.

```bash
# Из корня проекта в WSL; tools/env.sh содержит пути этой машины.
source tools/env.sh
python3 tools/prepare_runtime.py
python3 tools/prepare_models.py
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

Для другой машины задайте JAVA_HOME, ANDROID_HOME, GRADLE_USER_HOME и `sdk.dir` в `local.properties`. Python bootstrap не требует сторонних пакетов. Скачивание выполняется при явном запуске скриптов. Модели не включаются в APK.

## Установка

```bash
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb push model-pack/replika-offline-pack.zip /sdcard/Download/
```

Откройте REPLIKA → Модели → Импорт offline pack → ZIP в Downloads. Либо загрузите нужные наборы из приложения, подтвердив расход трафика. Для основного конвейера нужны GigaAM v2, Silero VAD и Pyannote + 3D-Speaker; Whisper tiny устанавливается отдельно. Выберите ASR до запуска обработки. После установки включите авиарежим, импортируйте аудио и нажмите «Создать стенограмму».

Минимум Android 8.0 (API 26); APK содержит arm64-v8a и x86_64. Рекомендуется телефон с достаточным объёмом RAM. Для длинных записей текущая нативная диаризация требует целый PCM-массив; приложение проверяет доступный Java heap и сообщает о нехватке памяти.

## Работа

Импорт WAV / MP3 / M4A использует системный файловый выборщик и локальную копию аудио. Фактические кодеки зависят от Android MediaCodec. Запись использует AAC/M4A, показывает настоящий уровень микрофона и ставится на паузу при уходе приложения в фон. Продолжение записи выполняется пользователем. Обработка сохраняется в WorkManager и не привязана к Activity.

В стенограмме нажмите реплику для перехода к звуку. Меню реплики открывает прослушивание участка, текст, выбор говорящего и отметку проверки. Нажатие имени открывает переименование. Smart Review фильтрует вычисленные предупреждения. Изменения сохраняются в Room и сразу отражаются в экспорте.

Экспорт TXT / SRT / JSON открывает системное меню Share. JSON включает миллисекунды, backend, исправления, предупреждения и диагностику. Имена участников задаются вручную. Confidence и word timestamps не выдумываются.

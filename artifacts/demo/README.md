## Что показывает видео

Сценарий соответствует проверке экспертами:

1. Телефон в режиме полёта — сеть не используется.
2. Установка APK и первый запуск: модели распаковываются и проверяются локально.
3. «Импорт» на главной → выбор аудиофайла в системном диалоге.
4. Режим «Количество говорящих: Автоматически» → «Создать стенограмму».
5. Обработка в фоне: уведомление с ходом работы.
6. Готовая стенограмма: реплики, говорящие, время; нажатие на реплику
   включает звук с этого места.
7. «Экспорт» → JSON. Показ файла в формате жюри:
   `{"transcript":[{"speaker_id":"speaker_1","start_ms":…,"end_ms":…,"text":"…"}]}`.

## Как добавить видео

Видеофайлы большие, поэтому в Git их лучше не класть. Варианты:

- приложить файл к GitHub Release и дать ссылку здесь;
- загрузить на видеохостинг и дать ссылку здесь.

Если файл всё же кладётся в репозиторий — имя `demo.mp4` в этой папке.

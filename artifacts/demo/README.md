# Видеодемонстрация

**Файл:** [`demo.mp4`](demo.mp4) — 2 мин 05 с, 1920×1080, 30 к/с, тихая музыка
(можно говорить поверх). Та же копия приложена к GitHub Release.

## Что показывает видео

Все кадры приложения — настоящие записи экрана REPLIKA 1.7 (`adb screenrecord`),
ускоренные участки помечены в кадре («×6», «×10» и т. д.).

| Время | Сцена | Что видно |
| --- | --- | --- |
| 0:00 | Вступление | «Встреча закончилась. Стенограмма уже готова. Без интернета.» |
| 0:12 | Первый запуск | распаковка и проверка 994,7 МБ моделей из APK, без сети (×6) |
| 0:20 | Запись | пузырь, запись → пауза → продолжить → удалить (×1,5) |
| 0:36 | Импорт | «Импорт аудио или видео» → файл → обработка стартует сама (×10) |
| 0:56 | Стенограмма | реплики по говорящим и время, плеер, нажатие на реплику, режим «Чтение» (×2) |
| 1:14 | Результаты | WER 23,3% → 13,3% (dev), на Android 17,0% → 9,7%; DER 43% → 18%; верное число говорящих 5/23 → 16/23; RTF 0,35–0,41 на телефоне; до 8 ч при памяти ≤ 0,92 ГБ; RU/EN 28/28 |
| 1:39 | English | автоопределение языка → Parakeet TDT v2 (×3) |

Формат JSON в кадре — настоящий экспорт этой записи:
`{"transcript":[{"speaker_id":"speaker_1","start_ms":320,"end_ms":5320,"text":"Да, конечно, Света. …"}]}`.

## Устройство и ограничения записи

- Экран снят на x86_64-эмуляторе Android (программная графика, 4 ядра), а не на телефоне.
  Обработка 59-секундной записи на нём заняла около 4 минут, поэтому этот участок ускорен ×10.
  Скорость на реальном телефоне (vivo, ARM, 8 ядер): RTF 0,35–0,41 — см.
  `artifacts/test-results/step-12-device/README.md`.
- На эмуляторе нет микрофона, поэтому частицы на экране записи (появляются только от голоса)
  в ролик не попали; пузырь реагирует на касания.
- Цифры в сцене «Результаты» взяты из `docs/TEST_RESULTS.md` и `docs/STEP_*.md`.

## Как пересобрать ролик

Проект HyperFrames лежит вне репозитория (`C:\R\replika-video`: `build_comp.py` генерирует
`composition/`, затем `npx hyperframes check` и `npx hyperframes render --quality delivery`).

Скрипты исторические: используют зафиксированный staging аудио/весов и пишут результат под фиксированным именем, без собственной защиты от перезаписи. Запускать только в **отдельном свежем staging**, содержащем замороженные входы, результаты NN, нужные версии исходников из снимков и pinned host-окружение. Исходные внешние аудио/веса должны быть доступны по историческим путям. Не запускать в рабочем дереве поверх имеющегося аудита.

Пример для C1 после подготовки такого staging и активации pinned Python-окружения:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=. python - <<'PY'
from pathlib import Path
import runpy
target = Path("artifacts/test-results/step-04/full-c1-equivalence-audit.json")
assert not target.exists(), "Нужен свежий staging: перезапись запрещена"
runpy.run_path("artifacts/test-results/step-04/runner-snapshots/53f3f9941dc25e120283739f18803fba7e760819bf91253aee15b0c715c294cf.py", run_name="__main__")
PY
```

Для C2 проверяются оба отсутствующих выхода `full-c2-equivalence-audit.json` и `.md`, затем вызывается второй снимок. Эти аудиторы читают сохранённые NN-данные и пересчитывают метрики; модели не запускаются. Успех host-аудита не означает Android/ARM/телефонную или общую natural-dialogue приёмку.

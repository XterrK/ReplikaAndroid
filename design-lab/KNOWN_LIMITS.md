# Ограничения этапа concept review

- Человек ещё не выбрал направление. Нет нативной V1.4, финального APK, новых native screenshots, измеренных animation frame timings или приёмки vivo.
- Лаборатория полностью изолирована от Android Gradle/runtime. Все тексты/модели/волны/прогресс здесь fixtures. Аудио, ASR и Room не вызываются. Правка не переживает reload; экспорт содержит лишь вымышленные данные.
- Клавиатура — обозначенная имитация, font130 — CSS stress state. Настоящие Android IME, system font scale, TalkBack и сохранение исправлений проверяются отдельно после выбора.
- В A waveform занимает больше высоты Dialogue. В B gutter сужает русский текст, диапазон может переноситься на две строки. В C serif/крупный размер повышает scroll cost на компактном экране. Это реальные компромиссы вариантов, не подтверждённые результаты UX-исследования.
- Точное nested warning provenance legacy строк утрачено. Восстановить его без нового источника нельзя. Механизм ошибочного <700ms текста воспроизведён; именно 17 предупреждений пользовательской записи не воспроизведены без diagnostics.
- Automatic diarization по-прежнему содержит отдельный ML-дефект; новый дизайн его не исправляет.
- Browser plugin отсутствует. Установленные Chromium1248 binaries оказались обрезаны; сохранены failures. Рабочие captures получены уже существующим Chromium1193 из FI recovery с локальными shared libraries, без установки новых зависимостей.
- OS4 controller действительно отклоняет три направления: требует 6–10. Число направлений не подделывается, движок/SQLite не меняются. Ручной concept workflow сохраняет требуемый человеческий выбор; автоматический HUMAN_CONCEPT_REVIEW gate не заявляется пройденным.
- Первый Android baseline содержит системный ANR и падения UI-тестов. Исходные failures и результаты адресного повтора хранятся раздельно. Окончательные цифры — в `evidence/baseline/BASELINE_REPORT.md`.
- Новая clean build, V1.4 instrumentation acceptance, fresh offline provisioning, upgrade и итоговая поставка выполняются после утверждённого native implementation. Успешный browser QA не заменяет эти проверки.

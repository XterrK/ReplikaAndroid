# Reference expedition · 2026-11-05

Метод: web search и open официальных страниц через web tool. Исследованы заголовки, текст и доступные image links; личные аккаунты и закрытые editor demos не открывались.

1. [Linear, How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui). Авторы описывают снижение шума chrome, выравнивание и иерархию навигации. В B переносится дисциплина сетки и плотность, не desktop layout.
2. [Bear](https://bear.app/). Представлены mobile editor и темы, текст стоит в центре интерфейса. В C переносится читательское пространство; облачная модель и функции Bear не копируются.
3. [Rev Transcription Editor](https://support.rev.com/hc/en-us/articles/29824992702989-Transcription-Editor). Editor объединяет прослушивание, corrections и speaker labels; timestamp у имени переводит звук в нужную точку. REPLIKA сохраняет сегментный seek без выдуманных word timestamps.
4. Native REPLIKA: `docs/test-evidence/v1.3/final-results/01-dialogue-controlled.png` и `docs/human-review/v1.2/14-smart-review-real-warning.png` открыты через view_image. Первый показывает объединённые части под общим header, второй — старый <700ms warning. Это controlled/public fixtures, не исходная запись vivo.

Pinterest/Behance/21st/React Bits не исследованы; claim об их использовании не делается. Продуктовая основа — аудиоредактор/стенограмма; website templates не переносятся в Compose.

# UI V1.7 — скриншоты «после»

Сняты 07.11.2026 на своём x86_64-эмуляторе `emulator-5600` (AVD `ReplikaUi35`, Android 15 / API 35, 1080×2400, 420 dpi, программный GPU SwiftShader) с ветки `hack/task-11-ui-v17`. Это эмулятор, не телефон: цвета, плавность и нагрев на vivo не проверялись.

Экраны с данными (`02`, `05`, `06`, `12`, `13`) — сборка allInOneQa: реальный импорт `dialog-two-speakers.wav` (dev-01, 1:09, два диктора) через системный выбор файла → «Создать стенограмму» → GigaAM v3 + диаризация на эмуляторе.

# V1.7d — частицы

`particles-silence-noise-speech-silence.mp4` — запись экрана своего эмулятора `emulator-5600` (API 35, SwiftShader) во время `ParticleShowcaseV17Test`. Огибающая **задана тестом** (это витрина, не микрофон): 1.5 с тишины → 2.5 с фонового шума ~0.1 → 6 с «речи» со слогами ~4 Гц и паузой на вдох → 3 с тишины. Программный GPU не успевает за реальным временем, поэтому в ролике сцена идёт примерно в 1.5 раза медленнее.

Что видно: в тишине и шуме — ни одной частицы (шумовой порог); на голосе снизу поднимаются светящиеся кометы с хвостом, цвет по пути синий → фиолетовый → розовый, траектории закручиваются и ускоряются у плёнки; при касании — вспышка, искры вдоль плёнки и лёгкая вмятина; после голоса поток мягко затухает (спад ~0.6 с).

`frame-comets-and-sparks.png` — кадр крупно; `timeline-1fps.png` — раскадровка по секунде.

# V1.7c — реакция пузыря на тапы

Свой эмулятор `emulator-5600` (API 35, SwiftShader, 1080×2400), debug-сборка, идёт запись (тишина эмулятора, частиц нет).
`taps-right-left-top-bottom-then-burst.mp4` (8.7 с, `adb shell screenrecord`): тап справа → слева → сверху → снизу с паузой ~1.4 с, затем 4 тапа одновременно с четырёх сторон и 6 случайных тапов подряд.
`frames-*.png` — раскадровка 8 кадров/с (область пузыря). Видно: вмятина с той стороны, где был тап, выпячивание по бокам, волна обходит контур и затухает примерно за секунду; при серии — несколько вмятин сразу; после — снова круг.
Задержка `adb input tap` на программном GPU ~0.2–0.4 с, на телефоне отклик будет быстрее.

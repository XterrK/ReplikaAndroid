## Что сделано

| Пункт ТЗ | Реализация |
|---|---|
| 1. Палитра | `Theme.kt`: `Brand` = `#3D7BFF → #8A5CFF → #FF4FA3` (пузырь, частицы, иконка); для поверхностей с белым текстом — `Brand.strong` `#2F66EB → #7646EE → #D3307D` (белый текст ≥ 4.68:1 на каждой точке). Фоны `#0E0F13` / `#F6F7FB`. Текст: onSurface 17:1, вторичный `#A3A6B4` / `#5B6070` ≥ 5.4:1, акцент `#8FB2FF` / `#2C5BD8` ≥ 5.4:1. Градиент на кнопке «Импорт», активной вкладке, таймере, «Воспроизвести», «Создать стенограмму», логотипе. |
| 2. Шрифт | Только Onest: один variable-файл, веса 300–700 через ось `wght`. `EditorialFont` (Serif) упразднён. Шкала: Display 32/Bold, Title 22/SemiBold, Body 16/Regular, Caption 13/Medium; межстрочный 1.35–1.45. Шапка стенограммы: заголовок на всю ширину (до 3 строк), язык/длительность/«Локально» — отдельной строкой `FlowRow` с отступом 12 dp. |
| 3. Шар | `LiquidVoiceOrb.kt`: AGSL-плёнка (API 33+) с тонкоплёночной интерференцией (RGB 650/532/450 нм, толщина стекает вниз и закручивается), френель по краю, прозрачная середина, блик, отражение дальней стенки, мягкое свечение и тень. Граница пузыря передаётся в шейдер 8 гармониками Фурье контура. Canvas-fallback (API 26–32): прозрачное тело, вращающийся sweep-градиент обода, плёночные пятна, блики. `OrbDynamics.kt`: желейная мембрана — 32 массы на пружинах к покою и к соседям (wave + damping), `impact(angle, strength)` даёт вмятину, нормализация площади выдавливает бока, волна обегает контур и затухает. Тап — вмятина в точке касания, перетаскивание тянет плёнку (как раньше), голос раскачивает моды. |
| 3. Частицы | `VoiceParticles.kt`: `VoiceParticleSystem` (предвыделенные массивы, без аллокаций на кадр) + `VoiceParticleField` — полноэкранный overlay вместо правой волны. Частицы стартуют с нижнего края, число (3…55/с) и скорость (230…870 dp/с) — от реального уровня MediaRecorder; ниже порога тишины и на паузе новых нет. Долетая до контура, бьют пузырь (`impact`), остаётся короткая вспышка. Семантика уровня микрофона сохранена (`progressBarRangeInfo`, «Тишина»/«Звуковой сигнал»). |
| 3. Кадры | Каденция шара не менялась (`OrbFrameCadence`: 30 fps в тишине, 60 на речь/касания/удары — удары входят в `hasInteractionMotion`). Частицы: цикл кадров только пока идёт запись или летят частицы; в тишине — опрос раз в 90 мс. Нагрев/энергосбережение: общий `powerFrameLimit`; при сильном нагреве частицы не запускаются. Reduced motion (animator scale 0): мембрана и частицы выключены, остаётся реальный уровень. |
| 4. Запись | `RecordingHome.kt`: ряд `✕` 56 dp · `⏸/▶` 72 dp (градиент) · `✓` 56 dp (градиентная обводка) с подписями и contentDescription. `✕` ставит на паузу и спрашивает «Удалить запись? Это нельзя отменить»; «Отмена» возвращает прежнее состояние (шла запись — продолжается). `✓` сохраняет и сразу открывает запись с «Создать стенограмму». Стрелка/системный «назад» — прежний выбор «Сохранить / Удалить» с паузой. Черновик не попадает в Room до сохранения, таймер сбрасывается. Шапка «← Запись» заменена стрелкой без текста. |
| 5. Навигация | Вкладки «Запись · Библиотека · Модели» (`ReplikaTabBar`, градиентная плашка у активной). Главная: без «Экспорт» и без дублирующей подсказки — одна строка статуса под пузырём и кнопка «Импорт аудио или видео». Библиотека: один заголовок, карточка — название, «00:22 · 2 говорящих · RU», первая строка текста; статус только если не готово. Стенограмма: язык в строке метаданных, вместо «Диалог» + немых иконок — чипы «Все участники / Автопрокрутка / Проверка», точка цвета говорящего вместо дубля номера. Модели: «Язык: автоматически» + строки RU · GigaAM v3 / EN · Parakeet TDT v2, все карточки со скруглением 16 dp. |
| 6. Иконка | `mipmap-anydpi-v26/ic_launcher(_round).xml`: фон — градиент бренда, передний план — стеклянный пузырь с радужной кромкой, бликом и звуковой волной (в безопасной зоне 66 dp), монохромный слой для themed icons. `ic_replika` (значок уведомления) — белый контур того же знака. Всё векторное. |

Дополнительно (замечено при проверке): экран первого запуска All-in-One (`ModelPreparationScreen`) переведён на новый стиль и перечисляет обе ASR-модели; панель «Готово к обработке» — отступы 12 dp, кнопка «Создать стенограмму» градиентная; «Сохранить запись» в листе выбора — градиентная; подписи вкладок ограничены масштабом 1.3×, чтобы «Библиотека» не обрезалась при шрифте 2.0; превью в карточке склеивает первые короткие реплики («Да, но это значит…»).

### Известные ограничения

- `ThemeBarsV15Test` падает на этом эмуляторе API 35 на первом снимке после смены темы против системной: SystemUI не перекрашивает кнопки трёхкнопочной навигации («Home glyph contrast» 1.6–2.0). **Проверено на базовом `hack/final` 1a856dfa — падает так же**, то есть это не регрессия; флаги окна выставляются верно. Исторически тест проходил на API 28.
- Окружение для UI-тестов: перед прогоном нужны `files/integration-example.wav` (как в `tools/stage_android.py`), выданный `POST_NOTIFICATIONS` (иначе системный запрос перекрывает приложение, когда фикстура ставит «обработку») и для `RecordingPermissionV14Test` — отозванный `RECORD_AUDIO`.
- `AllInOneUiTest`, `ProductExperienceTest`, `ReviewScreenshotsTest`, `Plan19ImportFormatsTest` изменены только механически (вкладки по тегу `tab-*`, экспорт по `workspace-export`), скомпилированы, но в этой сессии не прогонялись — им нужна установленная модель/фикстуры.
- Частицы видны только при реальном звуке: на эмуляторе вход микрофона — тишина, поэтому на скриншотах записи их нет; кадр с частицами — визуальная фикстура (уровень задан тестом). На физическом микрофоне, телефонном GPU и по нагреву редизайн не проверялся.
- Сборка в worktree: `tools/build_portable.py` отвергает junction на `model-pack`/`jniLibs`, поэтому Gradle вызывался напрямую с `-PreplikaPython=<python 3.12>`.

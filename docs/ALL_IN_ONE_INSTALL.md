# REPLIKA V1.5 — установка и локальный импорт видео

Установочный файл для Android arm64-v8a: `release/REPLIKA-V1.5-AllInOne-arm64.apk`. Контрольная сумма финального APK хранится рядом в `.apk.sha256`; результаты его проверки — в [отчёте V1.5](../TEST_REPORT_V1_5.md). Минимальная версия Android — 8.0 / API 26, target API 35, versionCode 7, applicationId `ru.replika.offline`.

APK содержит GigaAM v3, VAD и модели разделения говорящих. Скачивать веса или выбирать ZIP при первом запуске не требуется. Whisper удалён из текущего комплекта, выбора моделей и собственного JNI runtime. Старые стенограммы Whisper остаются читаемыми и экспортируются со своей исходной атрибуцией.

## Установка

1. Передайте APK на телефон и откройте штатным установщиком Android. При обновлении совместимой REPLIKA с той же подписью установите поверх приложения. Сохранённые записи и ручные исправления остаются в Room; удалять приложение или очищать данные не нужно.
2. Запустите REPLIKA и дождитесь проверки, подготовки и SHA-256-проверки моделей. Сеть для этих стадий не требуется. Прогресс подготовки отражает обработанные байты текущей стадии, а не оставшееся время.
3. После подготовки откроется главная с Liquid Voice Orb. Нажатие на шар запускает запись после разрешения Android на микрофон. Пауза, продолжение и остановка доступны отдельными кнопками.
4. «Импорт» принимает аудио и видео. После извлечения звука откроется обычный экран выбора режима говорящих; распознавание запускается отдельно. Для монолога выберите «Один говорящий». Automatic diarization остаётся известным дефектом и может неверно определять число участников.
5. Записи находятся в отдельной вкладке «Записи». Экспорт доступен на главной и в готовой стенограмме.

Светлая, тёмная графитовая и системная темы выбираются в настройках; режим сохраняется локально в DataStore.

## Текущий комплект

В манифесте **семь файлов и три группы**:

| Группа | Состав |
|---|---|
| `giga-v3` | GigaAM v3 E2E RNNT INT8: encoder.int8.onnx, decoder.onnx, joiner.onnx, tokens.txt |
| `vad` | Silero: silero_vad.onnx |
| `diar` | Pyannote segmentation-3.0: segmentation.onnx; 3D-Speaker ERes2Net: embedding.onnx |

Подготовленные веса занимают **278 127 730 байт** (265,24 МиБ). Отдельный исходный ZIP `model-pack/replika-offline-pack-v1.5.zip` занимает **278 569 170 байт**, SHA-256 `5e064a64e7a2511b5b2cc8b51989a3bafac57719a3d9bb062fb60e10d2af73c6`. Встроенный DEFLATE ZIP занимает **208 854 459 байт**, SHA-256 `2c12dfd8a000b2432cae606d6b849dd9b39ce205d50cc49c70a4f9a3253003d0`.

Состав и хеши файлов заданы в [models-lock.json](../app/src/main/assets/models-lock.json), проверенный локальный inventory — [current-model-pack-verification.json](test-evidence/v1.5/current-model-pack-verification.json). Итоговый APK проверяется отдельно; хеш ZIP не является хешем APK.

Для чистой подготовки установщик требует размер отсутствующих моделей плюс резерв 32 МиБ: **311 682 162 байта** для полностью нового комплекта. APK к этому моменту уже установлен и занимает отдельное место. Это программный порог подготовки, а не измеренный минимальный объём свободного места для установки Android. Записи, база, экспорты и подготовка звука требуют дополнительного пространства.

При обновлении старые GigaAM v2 файлы могут сохраняться для совместимости с прежней установкой; они не входят в новый APK и увеличивают фактический объём данных. Удаляется только точный файл снятого Whisper в принадлежащем приложению каталоге моделей. Исторические внешние ZIP и APK не изменяются.

## Импорт видео

REPLIKA читает документ через системный content provider и извлекает одну звуковую дорожку без декодирования видеокадров и без полной копии видео. Исходный документ остаётся на месте. Для нескольких дорожек выбирается первая, отмеченная системой основной; если такой метки нет — первая аудиодорожка. После импорта показывается уведомление об этом выборе.

AAC с нулевым первым timestamp переносится в M4A без повторного кодирования. Для других системных аудиокодеков и смещённого начала звука используется mono PCM WAV; исходная временная шкала сохраняется, включая тишину перед началом дорожки. WAV может занимать больше места, чем сжатая звуковая дорожка. Поддержка контейнеров и кодеков зависит от Android и устройства; защищённые, повреждённые файлы и видео без звука дают понятную ошибку. Для cloud provider может потребоваться его собственная загрузка файла до открытия документа.

Импорт можно отменить. Неоконченные аудиофайлы удаляются, исходник сохраняется. При записи и ML используется прежний локальный pipeline; отдельной сессии микрофона для шара нет. Подробности — [VIDEO_IMPORT_TECHNICAL_SPEC.md](../VIDEO_IMPORT_TECHNICAL_SPEC.md).

## Повторный запуск и восстановление

Проверенные веса повторно не распаковываются. После прерывания подготовки приложение проверяет временные файлы и продолжает безопасную установку. Тяжёлый архив читается потоково вне UI-потока. Ошибки нехватки места или памяти предлагают освободить ресурсы и повторить подготовку.

В «Модели» отображается один активный GigaAM v3 и фактическое состояние трёх групп. «Расширенное управление» позволяет восстановить комплект из APK без сети, импортировать совместимый offline pack или удалить модель с подтверждением. В стандартной сборке веса отсутствуют, ручной импорт и явная загрузка по pinned-манифесту сохранены.

Локальная сборка:

```bash
python3 tools/prepare_current_pack.py
python3 tools/build_local.py :app:assembleAllInOne
```

Первая команда использует уже имеющиеся локальные веса и создаёт отдельный V1.5 ZIP. Для явной загрузки точных файлов текущего манифеста предусмотрен `tools/prepare_models.py`. Обычная Gradle-сборка ничего не скачивает из моделей. В APK arm64 включаются `libsherpa-onnx-jni.so` и `libonnxruntime.so`; собственного `libreplika-whisper.so` больше нет. Итоговый файл сборки: `app/build/outputs/apk/allInOne/app-allInOne.apk`.

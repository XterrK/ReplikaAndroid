# REPLIKA V1.2.1 — установка одним APK

Основной файл для vivo X300 и других совместимых Android arm64-v8a:

`F:\Hackathons\ReplikaAndroid\release\REPLIKA-V1.2.1-AllInOne-arm64.apk`

APK содержит весь офлайн-комплект. Скачивать модели или выбирать ZIP при первом запуске не требуется. Минимальная версия Android — 8.0 / API 26; целевая версия сборки — API 35. Совместимость именно с физическим vivo X300 должна подтверждаться отдельной приёмкой, а не результатами эмулятора.

Артефакты собраны и сохранены отдельно:

|---|---|---|
| REPLIKA-V1.2.1-AllInOne-arm64.apk | 377 401 829 байт, около 377,4 МБ | `72fb824fc4356f72b22a57a1f7ac8a3221c29361d7feec35c0d1710cf2554aaa` |
| REPLIKA-V1.2.1-Standard.apk | 129 392 247 байт, около 129,4 МБ | `3c4412b29cf0e7d94e5283658d2feb9da96e356bf9df05325cae7aa18195d92f` |

Первый запуск проверен на QA-варианте x86_64 в эмуляторе API 35 с размером страниц 4096 байт. Физическая проверка arm64 / vivo X300 — **BLOCKED**: телефон недоступен. Подробности и границы проверки: [отчёт](ALL_IN_ONE_TEST_REPORT.md), [известные ограничения](ALL_IN_ONE_KNOWN_ISSUES.md).

## Установка и первый запуск

1. Передайте на телефон один файл `REPLIKA-V1.2.1-AllInOne-arm64.apk`.
2. Откройте его и подтвердите установку штатным установщиком Android. При обновлении существующей REPLIKA устанавливайте поверх приложения, без удаления приложения и очистки его данных.
3. Запустите REPLIKA. Интернет не нужен; сценарий можно проверять с заранее отключённой сетью.
4. Дождитесь автоматической подготовки. Приложение последовательно показывает проверку файлов, подготовку моделей, проверку целостности и готовность. Прогресс относится к реально обработанным байтам текущей стадии; это не оценка оставшегося времени. Между стадиями счётчик может начинаться заново.
5. После успешной проверки SHA-256 автоматически откроется Library. Выберите запись для импорта или начните запись разговора. Для записи Android отдельно запросит разрешение на микрофон.

В комплект входят пять семейств моделей и восемь файлов:

| Назначение | Файлы |
|---|---|
| GigaAM v2 INT8 | encoder.int8.onnx, decoder.onnx, joiner.onnx, tokens.txt |
| Silero VAD | silero_vad.onnx |
| Pyannote segmentation-3.0 | segmentation.onnx |
| 3D-Speaker ERes2Net embeddings | embedding.onnx |
| Whisper tiny multilingual | ggml-tiny.bin |

Общий размер подготовленных моделей: **365 008 680 байт**, около **365 МБ / 348,1 МиБ**. Встроенный сжатый ZIP занимает **281 336 043 байта**. Точный состав, размеры отдельных файлов и SHA-256 заданы в `app/src/main/assets/models-lock.json`.

## Свободное место

Проверка места в установщике моделей требует после установки APK для чистой подготовки размер моделей плюс резерв 32 МиБ: **398 563 112 байт**, около **399 МБ / 380,1 МиБ** свободного внутреннего хранилища. Это программный порог подготовки, а не измеренный минимум установки Android. APK при этом уже установлен и занимает отдельное место. Аудиозаписи, база и экспорты требуют дополнительного пространства.

Перед передачей файла и установкой разумно освободить **около 1,5 ГБ**. Это оценка с запасом для переданного APK, установленного приложения, моделей и временных расходов Android, а не измеренный минимальный предел. Переданный APK на телефоне занимает место отдельно от установленного приложения. Измерений минимального свободного места на vivo X300 нет.

При восстановлении требуется место для недостающих или повреждённых файлов и резерв. Уже проверенные файлы повторно не распаковываются. Полный архив не загружается в оперативную память: чтение и запись выполняются потоково вне основного UI-потока.

## Повторный запуск, прерывание и ошибки

При следующем запуске приложение проверяет сохранённые файлы. Валидные модели остаются на месте; повторной распаковки всего комплекта не требуется. Проверка крупных файлов может занять время даже без распаковки.

Если приложение закрыли или процесс завершился во время подготовки, откройте его снова. Частично записанный временный файл будет переподготовлен; полностью подготовленные временные файлы могут быть использованы после повторной проверки. Доступ ML-конвейера открывается после успешной проверки комплекта. Проверенные рабочие модели, записи и стенограммы не удаляются установщиком моделей.

- **«Недостаточно места»**: освободите указанное количество внутреннего хранилища и нажмите «Повторить подготовку».
- **«Недостаточно памяти»**: закройте другие приложения и повторите подготовку.
- **«Подготовка не завершена»**: повторите попытку. Если встроенные данные повреждены и ошибка повторяется, установите актуальный APK поверх приложения; не удаляйте приложение для повтора.

В проверке на эмуляторе чистая подготовка после холодного старта заняла **29,437 с**, а повторная проверка готовых моделей — **0,844 с** без распаковки. После принудительного завершения процесса повторный запуск использовал два проверенных временных файла, распаковал оставшиеся шесть и опубликовал все восемь; этот проход занял **23,541 с**. Это результаты QA-варианта на API 35 / x86_64 / 4096 байт, не прогноз времени на телефоне.

При первой попытке на деградировавшем AVD наблюдался ANR; доказательства сохранены в `docs/test-evidence/v1.2.1/first-launch/`. После холодного старта эмулятора чистая переустановка того же QA APK прошла. Это не доказывает исправление причины ANR в продукте: см. [ограничения](ALL_IN_ONE_KNOWN_ISSUES.md).

## Модели и дополнительные действия

В Models отображается «Встроенный офлайн-комплект». Сообщение об установке и проверке появляется по фактическому состоянию файлов. Выбор GigaAM или Whisper и диагностика доступны сразу.

«Расширенное управление» изначально свёрнуто. В нём доступны:

- **«Восстановить из APK»** — повторная проверка всего встроенного комплекта и восстановление недостающих или повреждённых файлов без сети. Такое же действие доступно в меню отдельного набора.
- **«Импорт offline pack»** — дополнительный ручной импорт совместимого комплекта с проверкой по манифесту. Это необязательный шаг; произвольные неподдерживаемые веса механизм не принимает.
- Удаление модели с подтверждением. Записи и стенограммы сохраняются; встроенные модели можно вернуть из APK.

В обычной сборке прежний ручной импорт и загрузка моделей остаются доступными. Она не содержит встроенных весов. Текущий стандартный APK сохранён как `release/REPLIKA-V1.2.1-Standard.apk`, предыдущий — отдельно как `release/REPLIKA-V1.2-Standard-preserved.apk`.

## Обновление установленной V1.2

All-in-One использует прежний applicationId `ru.replika.offline`, versionCode `4` и существующую debug-подпись. Это позволяет установить его как обновление совместимой локальной V1.2 с той же подписью и более низким versionCode. Проверенные модели из прежнего импорта должны быть распознаны и сохранены; Room и пользовательское аудио не мигрируются упаковкой моделей.

Обновление с versionCode 3 до 4 фактически проверено на эмуляторе x86_64 в режиме того же applicationId и с совпавшей исходной подписью: сохранены все проверяемые значения Room для девяти записей, 13 сегментов и одного говорящего, SHA-256 11 аудиофайлов и время изменения всех восьми моделей. Это подтверждает проверенный сценарий обновления эмулятора; перенос вывода на физический arm64 требует отдельного теста. При отличающейся подписи Android отклонит обновление; не обходите это удалением приложения с важными данными.

## Воспроизводимая локальная сборка

Нужен существующий проверенный `model-pack/replika-offline-pack.zip` и соответствующий ему `app/src/main/assets/models-lock.json`, локальные native-зависимости, Android SDK / NDK, JDK и Gradle toolchain проекта. Веса повторно не скачиваются. Отсутствующий или повреждённый локальный пакет должен приводить к ошибке сборки All-in-One, а не к загрузке другой модели.

Из рабочей директории проекта в текущем WSL-окружении:

```bash
python3 tools/build_local.py :app:assembleAllInOne
```

Задача проверяет все восемь файлов по размеру и SHA-256, создаёт локальный build asset `offline/replika-models.zip` и включает его только в вариант All-in-One. Исходный ZIP не заменяется. В установочный вариант входят только native-библиотеки arm64-v8a; Whisper сохранён. Внутренний ZIP использует стандартный DEFLATE, APK хранит его без второго слоя сжатия.

При новой сборке Gradle создаёт `app/build/outputs/apk/allInOne/app-allInOne.apk`. Собранный и проверенный установочный файл перенесён в `release/REPLIKA-V1.2.1-AllInOne-arm64.apk`, поэтому прежний файл в build/ может отсутствовать. Для передачи используйте артефакт из release/ и SHA-256 из таблицы выше. Воспроизводимость здесь означает одинаковые проверенные локальные входные веса и процедуру сборки; побайтовая воспроизводимость всего подписанного APK отдельно не подтверждена.

Стандартная сборка остаётся отдельной:

```bash
python3 tools/build_local.py :app:assembleDebug
```

При новой стандартной сборке создаётся `app/build/outputs/apk/debug/app-debug.apk`; текущий проверенный файл перенесён в `release/REPLIKA-V1.2.1-Standard.apk`. QA-вариант All-in-One для x86_64 служит проверкам на эмуляторе и не заменяет arm64 APK для vivo X300.

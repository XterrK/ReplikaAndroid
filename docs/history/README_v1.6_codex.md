## Сборка

Проверенное окружение: Python 3.12+, JDK 17, Android SDK 35, Build Tools 35.0.0 и NDK 27.2.12479018 для strip-задач AGP. CMake и сборка Whisper JNI удалены; sherpa-onnx используется как проверенная готовая библиотека. Сборка без NDK не проверена. Gradle 8.13, AGP 8.9.2, Kotlin 2.1.20. Debug APK хранит DEX без сжатия для уменьшения работы ART на старте; веса моделей в него не входят. Все тяжёлые инструменты текущего окружения находятся в `F:\ReplikaToolchain`, проект — в `F:\Hackathons\ReplikaAndroid`.

```bash
# Из корня проекта в WSL; tools/env.sh содержит пути этой машины.
source tools/env.sh
python3 tools/prepare_runtime.py
python3 tools/prepare_models.py
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

В этом WSL для ускоренной сборки доступен `python3 tools/build_local.py`: он использует RAM-кэш и сохраняет checkpoint в `F:\ReplikaToolchain\gradle-cache-checkpoint.tar`. Постоянные SDK, NDK, веса и проект остаются на F:.

Для другой машины задайте JAVA_HOME, ANDROID_HOME, GRADLE_USER_HOME и `sdk.dir` в `local.properties`. Python bootstrap не требует сторонних пакетов. Скачивание выполняется при явном запуске скриптов. В обычный APK модели не включаются. Для All-in-One используйте текущий проверенный `model-pack/replika-offline-pack-v1.5.zip` и `python3 tools/build_local.py :app:assembleAllInOne`; сборка проверяет pinned manifest/SHA и не скачивает веса. Для создания ZIP используйте `python3 tools/prepare_current_pack.py`.

## Установка стандартного APK

```bash
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb push model-pack/replika-offline-pack-v1.5.zip /sdcard/Download/
```

Откройте REPLIKA → Модели → Импорт offline pack → ZIP в Downloads. Либо загрузите нужные наборы из приложения, подтвердив расход трафика. Для одного говорящего нужны GigaAM v3 и Silero VAD; для fixed/automatic дополнительно Pyannote + 3D-Speaker; Whisper больше не предлагается. Перед обработкой выберите «Один говорящий», «Фиксированное число говорящих» (2–20) или «Автоматически». Последний режим пока может ошибаться в количестве участников. Режим сохраняется в записи и диагностике. После установки включите авиарежим, импортируйте аудио и нажмите «Создать стенограмму».

Минимум Android 8.0 (API 26); APK содержит arm64-v8a и x86_64. Рекомендуется телефон с достаточным объёмом RAM. Для длинных записей текущая нативная диаризация требует целый PCM-массив; приложение проверяет доступный Java heap и сообщает о нехватке памяти.

## Работа

Стартовый экран — шар записи. «Записи» открывает библиотеку; «Экспорт» на главной выбирает готовую стенограмму. Импорт аудио (WAV / MP3 / M4A) и видео (например MP4 / WebM) использует системный файловый выборщик. Из видео сохраняется только звук: AAC remux в M4A без потери качества или decode в WAV с сохранением исходной временной шкалы. Видео без аудио получает понятное сообщение, отмена удаляет частичный файл. Исходник не изменяется. Фактические кодеки зависят от Android MediaCodec. Запись использует AAC/M4A, показывает настоящий уровень микрофона в шаре и отдельных шкалах справа. Нажатия/растягивание шара во время записи создают только упругие визуальные импульсы. Запись ставится на паузу при уходе приложения в фон. Продолжение записи выполняется пользователем. Обработка сохраняется в WorkManager и не привязана к Activity. Отмена показывает ожидание текущего native этапа; повтор разрешается после освобождения ML. Уведомление открывает приложение для управления обработкой. После перезапуска состояние сверяется с WorkManager.

В стенограмме нажмите реплику для перехода к звуку. Меню реплики открывает прослушивание участка, текст, поиск по списку говорящих и отметку проверки. Несохранённая правка явно отмечена; закрытие запрашивает подтверждение. После сохранения доступна отмена последней правки текущей сессии. Нажатие имени открывает переименование. Smart Review показывает очередь с объяснениями вычисленных предупреждений, прослушиванием и отметкой «Проверено». Пустая очередь не гарантирует правильность ASR. Изменения сохраняются в Room и сразу отражаются в экспорте. Удаление через меню записи требует подтверждения и удаляет только принадлежащую ей локальную копию аудио; исходник импорта и модели сохраняются.

Экспорт TXT / SRT / JSON открывает системное меню Share. JSON включает миллисекунды, backend, исправления, предупреждения и диагностику. Имена участников задаются вручную. Confidence и word timestamps не выдумываются.

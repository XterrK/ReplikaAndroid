# REPLIKA V1.4 — UX before / after

| Экран | До (V1.3) | После |
|---|---|---|
| Library | тёмно-синие поверхности, более рыхлые строки | холодная Light / нейтральная Graphite, editorial heading, поиск, компактные метаданные, быстрые Записать/Импорт, Настройки |
| Recording | история peak bars | Liquid Voice Orb с физическим path, AGSL/Canvas, один реальный MediaRecorder, явные состояния и отдельные действия |
| Processing | крупная панель этапа | общая палитра, читаемый реальный статус, без процентов; сохранена отмена и thermal policy |
| Dialogue | группировка нескольких исходных частей под одним заголовком, визуальная каша | отдельная исходная реплика с именем, цветом, таймкодом и редактированием; компактный transport |
| Reading | обычный body текст | просторный 18/29 sans для чтения, чистое копирование и исходные абзацы без пересказа |
| Review | унаследованный short flag ошибочно описывал длину объединённой строки | duration-only флаги исключены из очереди; полезные flags сохранены; исходные reasons не переписаны |
| Editor | крупные отступы и панель предупреждений | компактнее, обе темы, IME resize/insets; с клавиатурой видны текст, оригинал и сохранение, подробности доступны после её закрытия; Undo сохранён |
| Models | технические подписи в основном потоке | краткие описания движков и готовности; размер/SHA в расширенном управлении; диагностика доступна |

Две нижние вкладки сохранены вместо восьми вкладок C. Serif — только editorial headings; транскрипция, время и controls — Onest. Палитра — прямое уточнение пользователя, не буквальная бумага/терракота исходного C.

Из ML не изменены GigaAM, Whisper, VAD, диаризация, оптимизированный PCM, offline pack и thermal policy. Automatic diarization не объявляется исправленной.

## V1.5 — прямое пользовательское ревью

| Участок | V1.4 | V1.5 |
|---|---|---|
| Старт | Library | Главная «Запись» с шаром, быстрый Импорт и Экспорт; Library в «Записи» |
| Waveform | низкая дорожка, тесные и смещённые controls | большая дорожка, отдельные clocks, симметричный центральный Play 64 dp, удобные ±10 и скорость; компактный footer на 360dp, короткий transport в Review/Reading |
| Один участник | сплошной speaker цвет | голубой → розовый градиент; multi-speaker сохраняет смысл цветов |
| Orb | сдержанная реакция | более сильная ограниченная деформация с инерцией, tap/drag и отскок; реальный VU справа независим от жестов |
| Источники | аудиофайлы | аудио и видео; локальный remux либо PCM decode только звука, исходник сохраняется |
| Модели | GigaAM v2 + Whisper tiny | один выбранный GigaAM v3; исторические стенограммы Whisper остаются читаемыми |

Изменение модели/нормализации тихой речи документируется отдельными A/B результатами, не визуальным ревью. Automatic diarization по-прежнему не исправлена.

Дополнительное качество V1.5: если обычный VAD не нашёл ни одного участка, разрешён один RMS/headroom повтор только для детектора. ASR и оригинальный звук не нормализуются этим повтором. На7 авторских студийных RU whisper test-файлах Android35/28 получено9/84 ошибок, проблемный фрагмент восстановил21/23 слов; другие6 не заходят в retry. Это ограниченная студийная проверка, не обещание качества шёпота телефона.

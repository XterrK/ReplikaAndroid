# REPLIKA V1.5 — author-directed upgrade

Прямое указание пользователя: Whisper удалить из продукта/All-in-One; поддержать video→audio→text; стартовый экран — жидкая интерактивная сфера, библиотека — отдельная вкладка. Экспорт доступен с главной. C+B и две палитры сохраняются.

## Навигация и композиция

Главная «Запись»: REPLIKA / настройки / экспорт, статус настоящей записи, крупная сфера в открытом пространстве, независимый VU справа без оси/линии, таймер только у сессии. Idle: сфера запускает микрофон; рядом доступны Импорт и Экспорт. Active: tap/drag сферы — физическая игрушка; отдельные Пауза / Продолжить / Остановить. Скрытие сферы не останавливает и не имитирует микрофон. При активной сессии главная удерживает явные controls; Back предлагает завершение. Reduced motion сохраняет управление.

Библиотека: отдельная вкладка, поиск, компактные строки, готовность и быстрые действия. Импорт принимает audio/video, сообщает подготовку и ошибки. Экспорт главной открывает выбор готовой стенограммы и существующий export UI с реальными Room-данными.

Диалог: большой player — waveform 96–120 dp, полноценная touch seek area, timestamps и симметрично центрированные controls. Main play 64 dp, skip 48, speed отдельной строкой/правым control без сдвига центральной кнопки. Для одного известного участника waveform cyan→pink; для нескольких speaker colors/диаризация. Reading сохраняет компактный transport.

## Визуальный контракт

Milk #F5F5F6 / graphite #111214; поверхности нейтральны. Перламутровые cyan/lavender/pink акценты внутри waveform/orb, не синий фон. Onest в тексте/кнопках, serif в заголовках. Геометрическая деформация sphere + glints/refraction; агент orb владеет spring и material. Отдельный VU показывает только реальный voiceLevel, игровые импульсы в него не поступают.

## ASR контракт

Сначала официальные кандидаты и воспроизводимый A/B, затем оптимизация. GigaAM v3 — кандидат, не заранее объявленный победитель. Реальные whisper samples с эталонами ищутся публично; синтетическое уменьшение громкости маркируется отдельно. Ни ухудшение ordinary speech, ни рост hallucinations не принимается ради одного примера. Offline, thermal gate, VAD, diarization, Room edits сохраняются. Удаление Whisper прямо разрешено пользователем и переопределяет прежний preserve-Whisper контракт.

Физический vivo X300 не подключён. Предыдущий V1.4 APK и Human Review ZIP сохранены; push запрещён.

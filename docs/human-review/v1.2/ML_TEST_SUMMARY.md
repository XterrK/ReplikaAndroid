## Открытые ограничения

- **BLOCKED:** естественный русский многоголосный pipeline и независимый reference не предоставлены. Mono, crop и китайская диаризация эту проверку не заменяют.
- **BLOCKED:** физического arm64 нет; API 36 и Android с 16 KiB страницами недоступны. Успех на эмуляторе и статический alignment не доказывают исполнение на телефоне.
- **PARTIAL:** нет WER/CER/DER, оценки реальных перебиваний, длительных записей и нагрева. Peak RAM не измеряется, PSS snapshots не являются пиком.
- **NOT IMPLEMENTED:** автоматическое второе мнение Whisper на каждом сегменте и мгновенный abort JNI. Польза опционального второго ASR без эталона не доказана; текущий режим не добавляет скрытый тяжёлый inference.

Методика и условия последующей независимой оценки — [ML_REGRESSION_PROTOCOL.md](ML_REGRESSION_PROTOCOL.md). Отдельная успешная диаризация не принимается как качество готовой многоголосной стенограммы.

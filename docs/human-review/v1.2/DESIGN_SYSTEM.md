# REPLIKA V1.2 — native product design specification

Baseline: V1.1 commit6e3c8abcd885345b185c2a9131f69eb02e4eb029. Все19 screenshots, исходники Screens/Theme/VM и реальные exports изучены до изменений. Android Compose остаётся платформой; модели,100ms pre-roll, Room и Worker сохраняются.

## Визуальная система

Графитовый фон #0B1120; surface #101A2C, raised #162238; текст #EEF2FF, secondary #9BA8C1. Существующий electric blue #6687FF — действие/позиция воспроизведения. Mint #6CE5C0 — готовность/запись; Violet #B398FF и существующая палитра — только участники. Unknown всегда muted с явной подписью. Никаких декоративных градиентов или glass.

Шаги пространства4/8/12/16/24dp; радиусы12dp controls,16dp surface,20dp sheets. Touch targets≥48dp независимо от видимой иконки. Заголовки28/22/18sp, текст диалога16sp/24sp, metadata12–13sp; system font scale не блокируется. Основной контент имеет стабильный вертикальный ритм, декоративные рамки ограничены controls и активным состоянием.

## Информационная архитектура

Library: бренд/заголовок и короткая локальная подпись, запись+импорт, поиск, сразу список. Строка записи: название, длительность/дата, фактическая стадия, меню. Удаление — только через подтверждение; busy-запись сначала отменяется, собственность аудио проверяется в data layer.

Workspace: компактная шапка, один audio dock (waveform/позиция, speaker timeline, play/seek/speed), компактный toolbar «Диалог / Smart Review», затем непрерывная лента. Реплика — speaker rail + имя/интервал + текст + edit, без больших независимых карточек. Активная реплика выделяется синим и selected semantics. Время сегментное: подсветки слов нет.

Editor: развёрнутый sheet, скроллируемое тело, отдельный save footer над IME/navigation. Сохранённое и изменённое состояние различаются; потеря несохранённого требует подтверждения. Выбор участника — вертикальный поиск, длинные имена переносятся, unknown/new доступны. Save закрывает sheet только после Room acknowledgement. Undo ограничен последней правкой реплики текущей сессии и проверяет stale snapshot.

Smart Review: отдельная очередь объективных предупреждений с типом, объяснением, speaker, интервалом, прослушиванием и правкой/проверкой. Empty объясняет отсутствие вычисленных сигналов, не отсутствие ошибок ASR, и возвращает к диалогу. Второй ASR автоматически не запускается.

Recording: реальные amplitude samples с ограниченным stroke и фиксированным окном истории, явный timer/state/пауза. Никакого заполнения демонстрационными пиками. Действия доступны прокруткой на компактном экране/font1.3.

Models: выбранный ASR, проверка/размер каждого набора с KB/дробными MB, offline pack; компактная последняя диагностика с названием записи/backend и человеческими подписями. Технический JSON — отдельный details sheet/экспорт, не основной экран.

## Обязательные состояния и критерии

Loading отличается от empty по первому Room emission; данные привязаны к recordingId. Errors русские, действие восстановления конкретно, raw exception сохраняется в техническом журнале. Player не готовит повреждённый IMPORTED файл до намерения слушать. Нет точных ETA/процентов/AI confidence.

Проверка384dp и360×640dp при font1.3; светлая системная IME поверх тёмного sheet;12+ длинных имён участников. Реальные warning/ML screenshots снимаются после настоящего inference; искусственные warnings не добавляются. UI-only fixtures для длинных имён помечаются как ручные accessibility данные, не speaker recognition.

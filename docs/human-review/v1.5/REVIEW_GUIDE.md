# REPLIKA V1.5 — Human Review

Основа — утверждённый пользователем C+B, с холодной Light и нейтральной Graphite Dark. Это продолжение прямого пользовательского ревью, не новый выбор A/B/C.

## Что открыть

- `docs/human-review/v1.5/index.html` — локальная галерея оригинальных Android-скриншотов: две темы, два размера/шрифта и видео настоящего приложения.

- `release/REPLIKA-V1.5-AllInOne-arm64.apk` — настоящее Android-приложение с локальными моделями; обновление поверх V1.4 сохраняет пакет и Room.
- `TEST_REPORT_V1_5.md` — фактически выполненные проверки и ограничения.
- `MODEL_SELECTION_V1_5.md`, `ASR_QUALITY_V1_5.md` — выбор GigaAM v3 и воспроизводимые сравнения с v2, base RNNT и Parakeet.
- `evidence/android/` — итоговые Android-кадры обеих тем и компактного профиля. Имена `UI fixture` обозначают контролируемый текст для визуальной проверки, не результат ASR.
- `evidence/android-through-build6/` — промежуточный UI разных сборок до финального захвата. Ошибочные промежуточные capture не считаются приёмкой Editor.
- `evidence/orb-prototype/` — browser QA, явно симулированный уровень; `design-lab/index.html` — интерактивный прототип.

## Основной маршрут

1. Главная открывается с Liquid Voice Orb. Нажатие начинает запись после разрешения микрофона. Во время записи tap/drag растягивает тело с инерцией; правые шкалы продолжают показывать только реальный микрофон. Пауза, Продолжить и Остановить подписаны отдельно. Back предлагает сохранение/продолжение/удаление.
2. «Импорт» принимает аудио и видео. Звук видео извлекается автоматически на устройстве; следующий экран позволяет выбрать состав участников и начать обычное распознавание. Исходный файл не меняется.
3. «Записи» открывает компактную библиотеку. Откройте готовую стенограмму: большая waveform, симметричный Play и ±10 секунд, голубой/розовый градиент для одного участника. В маленьком окне footer уплотнён. Reading и Review сохраняют короткий transport для пространства текста.
4. Проверка и Editor позволяют прослушать оригинал, исправить текст/говорящего и сохранить. С клавиатурой видны поле и Save; Undo сохраняет возможность отменить правку. Очередь исключает малоценные duration-only предупреждения.
5. Экспорт доступен на главной: выбор готовой записи → TXT/SRT/JSON → системный Share. Используется текущий сохранённый текст Room. Ничего не отправляется автоматически.
6. Настройки позволяют выбрать Светлая / Тёмная / Как в системе; выбор переживает перезапуск. Whisper отсутствует в доступных моделях и новом APK, архивные стенограммы остаются читаемыми.

## Граница доказательств

vivo X300 не подключён. Запись, сохранение и микрофонные состояния проверяются на виртуальном Android; это не подтверждает аппаратную реакцию/нагрев/батарею телефона. Видео демонстрирует свой явно указанный источник. Ослабление PCM16 не называется настоящим шёпотом. Automatic diarization не исправлена.

Старые APK, прежние review ZIP и baseline Git сохранены. Push не выполняется. Полные hashes и состав новой поставки находятся в манифесте архива и отчёте.

Итог source11:80 JVM,97 уникальных Android-методов API35 и33 API28 прошли. Оригинальные результаты настоящего видеоимпорта и шёпота — `evidence/video-native11/` и `evidence/whisper-native11/`. Скриншоты настоящей готовой расшифровки видео в обеих темах — `evidence/native-demo/actual-video-transcript-LIGHT.png` / `...-DARK.png`. Они сохраняют реально полученный текст, не UI fixture. Новое видео source11 находится в `evidence/native-demo/native-orb-emulator-touch.mp4`; отдельные замеры и их ограничения — `performance-summary.json`.

Браузерный прототип запускается локальным сервером: из корня `python3 -m http.server 4174 --directory design-lab`, затем `http://localhost:4174`. Галерея `index.html` открывается локально без сервера.

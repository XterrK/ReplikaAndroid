# Human Review

Проверять нужно установленную Android-сборку. Иллюстрации и макеты не считаются скриншотами. Скриншоты, если получены, находятся в этом каталоге и сопровождаются указанием устройства/эмулятора и источника данных. При отсутствии файла сценарий не заявлен как визуально проверенный.

## Подготовка

Установить debug APK, импортировать проверенный offline pack через экран «Модели». Выбрать GigaAM v2. Включить авиарежим. Импортировать короткий русский диалог с согласия участников. Не использовать секретные или чужие приватные записи для демонстрации.

## Сценарии

| Экран | Действия | Что проверить |
|---|---|---|
| Library | Холодный запуск, импорт, повторный запуск, поиск по слову | История и названия сохранены, поиск находит текст готовой записи |
| Recording | Разрешить/отклонить микрофон, запись, пауза, продолжение, уход в фон | Уровень зависит от реального микрофона, таймер не идёт на паузе, фон приостанавливает запись |
| Processing | Запустить обработку, повернуть экран, вернуться из фона, отменить | Стадия настоящая, процентов нет, UI не зависает; отмена может ждать окончания текущего native вызова |
| Transcript | Нажать реплику, проиграть, перемотать, сменить скорость | Waveform соответствует исходной амплитуде, активная реплика меняется вместе с позицией |
| Speakers | Нажать имя, переименовать, открыть меню реплики, изменить участника | Цвета и фильтры согласованы, изменения переживают перезапуск |
| Smart Review | Включить фильтр, открыть предупреждение, прослушать, исправить, отметить проверенным | Причина вычислена, процентов confidence нет; карточка уходит из очереди проверки |
| Models | Удалить, прервать загрузку, повторить, импортировать повреждённый pack | Неполные веса блокируют inference; аудио не передаётся в сеть |
| Export | TXT / SRT / JSON → Share | Реальные имена, времена, исправления; JSON содержит фактический backend |
| Benchmark | Импортировать reference JSON из схемы после разметки | Нет фиктивной точности, результат связан с устройством и запуском |

## UX-аудит реализации

Тёмный сине-графитовый фон, electric blue, mint и violet используются функционально: акцент, готовность, участники. Первый экран объясняет идею и даёт запись/импорт. Основной workspace держит звук, timeline и стенограмму рядом. Второстепенные действия находятся в bottom sheets.

Системный font scale, узкий экран и длинные имена требуют проверки на физическом телефоне. Возможные слабые места: нижний sheet редактирования при открытой клавиатуре, горизонтальный список большого числа участников, слишком плотный waveform длинной записи. Запись при уходе в фон останавливается на паузе; это надо объяснять до интервью. Нет закреплённого контекста нескольких реплик в Smart Review, и нельзя отменить ручное исправление одним действием.

## Известные ограничения

Нет разделения слов одновременной речи, word-level timestamps и автоматической идентификации личности. Пунктуация русского ASR не восстанавливается. Длинные записи ограничены памятью нативной диаризации. Мгновенная отмена выполняющегося JNI не гарантируется. Автоматическое число участников не считается достоверным без DER на нужном корпусе.

Точная матрица фактически выполненных проверок — в корневом TEST_REPORT.md. Оценка компиляции, Linux smoke test, эмулятора и физического телефона ведётся раздельно.

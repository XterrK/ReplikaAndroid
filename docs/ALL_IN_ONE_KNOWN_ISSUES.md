## Границы подтверждённого первого запуска

На API 35 / x86_64 / 4096 байт после холодного старта чистая подготовка заняла 29,437 с. Повторная проверка заняла 0,844 с без распаковки. После принудительного завершения процесса следующий запуск повторно использовал два проверенных временных файла, распаковал шесть оставшихся и опубликовал все восемь за 23,541 с. Это время конкретного эмулятора и QA APK; оно не является SLA или прогнозом для vivo X300.

Исходный ANR сохраняется как открытая неопределённость до воспроизводимого выяснения причины и повторов в стабильных условиях. Успешный холодный повтор подтверждает прохождение сценария в этой среде, но не доказывает устранение дефекта.

Успешная установка моделей не доказывает качество распознавания. Результаты inference, Compose / instrumentation и запись с виртуального микрофона следует читать только в [итоговом отчёте](ALL_IN_ONE_TEST_REPORT.md), с указанием входных данных и фактической среды. Пока конкретный результат там не зафиксирован, данный документ его не объявляет успешным.
